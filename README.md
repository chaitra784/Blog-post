# 📝 BlogSpace - Blog Platform

BlogSpace is a full-stack blogging platform where users can register, log in, create blog posts, edit their posts, delete posts, view posts, and add comments.

---

## 🚀 Features

### 👤 User Authentication
- User registration
- User login
- JWT authentication
- Logout
- Protected pages

### 📝 Blog Posts
- Create posts
- View all posts
- View individual posts
- Edit posts
- Delete posts
- Search posts
- Author information
- Post date

### 💬 Comments
- Add comments
- View comments
- Login required for adding comments

### 🎨 Frontend
- Responsive design
- Purple theme
- Teal/green edit-post theme
- Mobile-friendly interface
- Navigation bar
- Forms and validation

### 🗄️ Database
- MySQL
- Users table
- Posts table
- Comments table
